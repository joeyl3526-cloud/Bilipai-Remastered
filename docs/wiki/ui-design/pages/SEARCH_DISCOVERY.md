## 初学者解释

搜索是“用户知道大概想找什么”，发现是“用户按热榜、话题、分区和分类继续浏览”。它们共享卡片与筛选，但输入焦点、查询保存和结果类型是搜索独有的关键状态。

## 规范要求

- 查询、筛选、结果和返回后的输入必须保持一致，清空查询不能等于离开页面。
- 结果类型可以分 Tab，但视频、用户、番剧、直播、话题与文章的跳转含义不可因风格变化。
- 600/840/1600dp 等当前特例仅由搜索布局策略使用并记录结构变化。

<a id="p005"></a>
## P005 综合搜索档案

- **用户目标**：输入关键词，查看建议与历史，并在多种内容结果中找到目标。
- **入口与出口**：首页/Story/其他搜索入口进入；出口为热榜、视频、网页、用户空间、番剧、直播、话题、文章、登录/个人及返回来源。
- **信息层级**：当前查询 > 输入建议/历史或结果类型 > 结果卡主信息 > 筛选与统计。
- **文字线框**：`返回 + 搜索框 + 头像 / 建议或历史 / 结果 Tab与筛选 / 结果列表网格 / 分页状态`。
- **设备适配**：Compact 搜索框占主宽；600/840dp 调整结果列与筛选；1600dp 限制内容并可使用侧区，不能让单条文本无限拉长。
- **组件清单**：`AppSearchField`、`AppScrollableTabRow`、筛选 chip/menu、视频/用户/番剧/直播/文章结果卡、共享状态组件。
- **状态矩阵**：首次加载=无查询时显示历史/建议，提交后按加载、阻塞失败、空内容、正常内容的优先级显示；刷新=保留查询和已有结果；部分数据=热榜/发现或某类型失败不遮其他内容；空内容=共享 `AppEmptyState(PAGE)` 并可改词；首次失败=共享 `AppErrorState(PAGE)`；分页加载/失败/结束=只出现在已有结果尾部，失败保留页码和结果并可重试；离线=历史可用、网络结果受限；未登录=公开搜索，头像导登录；权限不足=通常不适用；禁用=提交空查询或不可用筛选禁用。
- **交互和返回**：IME Search 与提交按钮一致；清空只清查询；顶部返回和系统返回优先关闭建议、清除输入焦点并隐藏键盘，再返回来源；结果详情返回恢复查询、类型、筛选和位置。
- **权限/登录**：基础搜索无需登录；个人化历史同步、账号操作按触发说明，不把未登录当失败。
- **性能**：建议防抖并取消旧请求；各结果列表稳定 key；图片按尺寸加载；切换 Tab 不重复无意义请求。
- **无障碍**：搜索框有标签，清空/提交/删除独立命名；Tab 交互区至少 48dp；错误使用礼貌级播报，空状态不重复播报；结果类型读出选中；卡片内容合并且不重复封面描述。
- **当前差距**：P005 已完成共享状态、分页失败保留和返回焦点试点；搜索布局拥有多个断点与局部 `GlassCard` 历史，其他页面仍待迁移。
- **验收**：输入快速变化的关键词、切换三种结果、打开详情再返回、清空；预期无旧结果覆盖新查询，焦点与列表位置合理。

<a id="p006"></a>
## P006 搜索热榜档案

- **用户目标**：浏览当前热门关键词并快速发起搜索。
- **入口与出口**：从综合搜索的热榜入口进入；点击词条提交到综合搜索，返回恢复原查询。
- **信息层级**：榜单顺序 > 关键词 > 热度/标签等辅助信息。
- **文字线框**：`顶部栏 / 更新时间或说明 / 排名列表 / 加载或错误`。
- **设备适配**：Compact 单列；宽屏限制列表阅读宽度，可分列但必须保持排名阅读顺序。
- **组件清单**：`AppScaffold`、`AppTopBar`、`AppListItem`、排名/热度标签、加载与错误组件。
- **状态矩阵**：首次加载=稳定行占位；刷新=保留榜单；正常=有序列表；部分数据=缺失热度仍显示关键词；空内容=提示暂无热榜并重试；失败=错误+重试；离线=可展示缓存并标明；未登录/权限不足=不适用；禁用=不可用条目不响应；分页加载/结束=通常不适用，若服务分页则按列表规则。
- **交互和返回**：点击词条只提交一次；返回回到搜索；刷新时排名变化不应把正在点击的行移走。
- **权限/登录**：不要求账号或系统权限。
- **性能**：列表 key 基于稳定关键词/服务 ID；更新时避免整页闪白。
- **无障碍**：读出“第 n 名、关键词、热度”，热度颜色不作为唯一含义。
- **当前差距**：热榜与搜索历史的卡面、更新时间文案需要与公共列表规则持续核对。
- **验收**：断网打开、恢复网络刷新并点击前后排名词；预期缓存/失败语义清楚，提交到正确查询。

<a id="p007"></a>
## P007 话题详情档案

- **用户目标**：理解一个话题并浏览其相关动态、视频、番剧、用户或直播内容。
- **入口与出口**：从搜索话题结果进入；出口到视频、番剧详情、用户空间、直播间、动态详情和返回搜索。
- **信息层级**：话题名称/摘要 > 主要相关内容流 > 作者和统计 > 次要筛选。
- **文字线框**：`返回+话题标题 / 话题摘要 / 内容筛选 / 混合内容流 / 分页`。
- **设备适配**：Compact 单列；Expanded 可采用内容网格但保持混合流时间/排序语义。
- **组件清单**：`AppTopBar`、话题头、Tab/筛选、共享内容卡、用户/直播卡、分页状态。
- **状态矩阵**：首次加载=头与内容分区占位；刷新=保留已读内容；正常=话题+列表；部分数据=头或某内容类型局部失败；空内容=话题存在但暂无内容；失败=无话题信息时整页重试；离线=缓存内容+标识；未登录=公开浏览；权限不足=不适用；禁用=失效内容不可点并说明；分页加载/结束=标准尾部状态。
- **交互和返回**：混合卡按内容类型跳转；返回恢复搜索位置；筛选切换保留各自合理位置。
- **权限/登录**：浏览不强制登录；互动动作触发时再引导。
- **性能**：混合列表稳定 key 包含内容类型；富文本和图片异步处理，不在组合期解析大对象。
- **无障碍**：头部只读一次；卡片声明内容类型；无效内容说明不可用原因。
- **当前差距**：不同内容类型卡片语义与共享状态可能仍不完全一致。
- **验收**：分别打开含多类型、仅单类型和空内容话题；预期跳转准确、局部失败不遮主体。

<a id="p045"></a>
## P045 内容分区档案

- **用户目标**：按 Bilibili 大分区浏览内容并进入视频、番剧或具体分类。
- **入口与出口**：首页快捷入口进入；出口到视频、番剧、分类和返回首页。
- **信息层级**：分区导航 > 当前分区内容 > 卡片标题/作者/统计 > 次级推荐。
- **文字线框**：`顶部栏 / 分区选择 / 当前分区推荐网格 / 刷新分页`。
- **设备适配**：Compact 分区选择可横向滚动；宽屏用稳定网格与最大卡宽，不出现挤压的小标签。
- **组件清单**：`AppScrollableTabRow`、分区 chip/menu、视频卡、番剧入口、PullToRefresh、状态组件。
- **状态矩阵**：首次加载=分区骨架+卡占位；刷新=保留当前分区；正常=分区流；部分数据=推荐区局部失败；空=当前分区暂无内容；失败=重试；离线=缓存/明确受限；未登录=公开浏览；权限不足=不适用；禁用=服务不可用分区不响应；分页加载/结束=尾部状态。
- **交互和返回**：切换分区不重复堆栈；视频返回恢复分区与卡位置；横向选择不抢整页返回。
- **权限/登录**：公开浏览无需登录，个性化动作按需引导。
- **性能**：每分区状态可缓存但有界；卡片图片按网格尺寸加载；快速切换取消旧请求。
- **无障碍**：分区读出选中状态与顺序；视频卡合并语义；刷新提示一次。
- **当前差距**：分区与首页卡片的来源 route/共享元素策略复杂，需要防止 key 不匹配。
- **验收**：快速切换三个分区、打开视频并分别正常/预测返回；预期来源正确且不出现黑底或错卡。

<a id="p057"></a>
## P057 视频分类档案

- **用户目标**：查看某个具体分类的视频列表并持续浏览。
- **入口与出口**：从首页或分区进入，携带分类 ID 与名称；出口到视频详情和返回来源。
- **信息层级**：分类名称 > 排序/筛选 > 视频列表 > 分页状态。
- **文字线框**：`返回+分类名 / 排序筛选 / 视频网格 / 尾部状态`。
- **设备适配**：Compact 选择合适单/双列；Expanded 增列并限制封面宽度；名称长时不挤掉返回。
- **组件清单**：`AppTopBar`、筛选控件、视频卡、`ContentCardSurfacePolicy`、加载/空/错误。
- **状态矩阵**：首次加载=标题立即可见+卡占位；刷新=保留列表；正常=分类视频；部分数据=统计缺失不阻塞；空=该分类暂无内容；失败=保留分类名并重试；离线=缓存或明确不可用；未登录=公开浏览；权限不足=不适用；禁用=无效分类提示并可返回；分页加载/结束=标准尾部。
- **交互和返回**：筛选改变时回到列表顶部并保留选择；详情返回恢复卡位置；无效参数安全返回而非崩溃。
- **权限/登录**：基础浏览不需要登录。
- **性能**：列表稳定 key；共享元素来源包含分类 route；分页去重。
- **无障碍**：分类标题、筛选当前值和卡片状态可读；空状态动作明确。
- **当前差距**：分类页 960/共享元素相关策略需要与通用列表母版继续校对。
- **验收**：测试有效、空、无效分类与分页末尾；预期标题、返回、错误和来源位置正确。

## 当前差距

搜索与发现页仍有不同布局策略、卡片变体和断点。P005 以共享输入、卡面和状态语义完成首轮试点；目标不是强行让所有内容都采用同一列数，而是保持功能、信息顺序和状态含义一致。

## 验收方法

按五个档案逐项执行查询、筛选、刷新、分页、详情返回和断网；在 360/700/840/1600dp 检查信息顺序、状态保存和卡片尺寸。
