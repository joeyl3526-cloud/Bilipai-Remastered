## 初学者解释

这组页面连接账号凭据、备份服务、插件运行时、外部媒体和网页。它们最大的 UI 责任是建立信任边界：用户必须知道内容来自哪里、要交出什么信息、失败后是否已经产生更改，以及怎样安全退出。

## 规范要求

- Cookie、token、验证码、WebDAV 密码和插件敏感数据禁止出现在普通日志、分享文本或崩溃摘要。
- 外部内容必须有明确来源、加载状态、返回和不支持协议回退，不能伪装成本地可信页面。
- 多步流程提交前预览影响；取消/失败后保持可解释且尽量原子化。

## P018 JS 插件内容档案

- **用户目标**：在应用内查看某个已安装 JS 插件提供的内容并安全打开其支持的媒体或链接。
- **入口与出口**：插件中心/插件入口携带 pluginId 进入；出口到插件媒体、应用内内容、Web 或返回插件中心。
- **信息层级**：插件身份/来源 > 插件内容 > 插件动作 > 运行错误与能力提示。
- **文字线框**：`返回+插件名 / 内容区域 / 插件动作 / 错误或权限反馈`。
- **设备适配**：Compact 单栏；Expanded 限制插件内容宽度，不能允许插件任意覆盖全局导航。
- **组件清单**：`BiliPaiJsPluginContentScreen`、`AppScaffold`、`AppTopBar`、受控插件渲染、状态组件。
- **状态矩阵**：首次加载=加载插件模块；刷新=受控重新加载；正常=渲染内容；部分数据=单模块/媒体失败局部；空=插件无内容说明；失败=隔离异常并重试/返回；离线=本地内容可用、网络能力受限；未登录=按插件声明但不能读取未授权凭据；权限不足=列出缺少能力；禁用=插件被禁用/不受信；分页加载/结束=由受控插件合同映射。
- **交互和返回**：插件动作通过受控 host；返回先关闭插件浮层再离开；不支持路由不执行任意代码。
- **权限/登录**：能力清单先授权；插件不能静默读取历史、反馈、网络或播放器控制。
- **性能**：运行时异常隔离、超时/资源有界；不在组合线程执行长脚本。
- **无障碍**：宿主导航始终可达；插件内容至少提供名称、角色、顺序和错误说明。
- **当前差距**：JS runtime 的可表达 UI 与无障碍覆盖需要按插件能力持续审计。
- **验收**：合法内容、空、脚本异常、网络失败、未授权能力和返回；预期插件异常不破坏主应用。

## P019 外部媒体播放档案

- **用户目标**：播放由插件或外部启动记录提供的媒体，并了解来源与可用控制。
- **入口与出口**：插件/外部流程携带 launchId 进入；出口回来源或安全结束播放。
- **信息层级**：媒体画面/音频 > 来源与标题 > 播放控制 > 不支持/错误。
- **文字线框**：`返回+来源 / 稳定媒体区 / 控制与状态 / 来源说明`。
- **设备适配**：嵌入、横屏与 Expanded 遵循媒体母版，不让不可信内容覆盖系统退出。
- **组件清单**：`ExternalMediaPlayerScreen`、播放器 surface、控制、状态层、来源标签。
- **状态矩阵**：首次加载=解析 launchId；刷新=重试源；正常=播放；部分数据=标题/封面缺失仍可播并显示来源；空=启动记录不存在；失败=解析/协议/播放错误；离线=本地/缓存源按实际；未登录=宿主不泄露凭据；权限不足=插件/网络/DRM 能力说明；禁用=不可信或不支持源；分页加载/结束=不适用。
- **交互和返回**：播放控制与系统媒体一致；返回释放专属 session；重试不重复播放器。
- **权限/登录**：只使用启动记录已授权能力；不把外部 URL 当可信文本记录。
- **性能**：源解析后台执行，播放器单一，离开释放。
- **无障碍**：来源、标题、播放状态和错误原因可读。
- **当前差距**：外部协议与普通播放器的控制共享程度有限。
- **验收**：有效、过期、不支持、离线 launchId；预期安全错误且不会进入死循环。

## P022 WebDAV 备份档案

- **用户目标**：配置 WebDAV、测试连接、备份或恢复设置/数据，并理解覆盖范围。
- **入口与出口**：设置工具进入；出口到系统文件/网络流程或返回。
- **信息层级**：服务地址/账号 > 连接状态 > 备份与恢复 > 覆盖范围/风险 > 历史结果。
- **文字线框**：`顶部栏 / 服务器表单 / 测试连接 / 备份恢复动作 / 进度结果`。
- **设备适配**：Compact 表单纵向；Expanded 限制字段宽度，结果/历史可在旁但流程顺序不变。
- **组件清单**：`WebDavBackupScreen`、`AppTextField`、密码字段、主按钮、进度、Dialog、Snackbar。
- **状态矩阵**：首次加载=本地配置（密码不明文展示）；刷新=测试/拉取远端；正常=可备份恢复；部分数据=远端列表失败但本地配置可改；空=无远端备份；失败=连接/认证/上传/下载/解析分别说明；离线=配置可改，网络动作禁用说明；未登录=与 Bilibili 账号无关；权限不足=文件/网络系统限制；禁用=字段无效或任务进行中；分页加载/结束=远端历史若分页。
- **交互和返回**：测试连接不等于保存/备份；恢复前预览范围并确认；任务中返回规则清楚；失败不留下半恢复。
- **权限/登录**：密码安全存储/遮罩，不写日志或分享；HTTPS/服务风险说明按实现。
- **性能**：上传下载后台且可报告进度；大文件流式处理；重复提交防护。
- **无障碍**：字段标签、密码显示切换、进度、失败原因和危险恢复可读。
- **当前差距**：备份覆盖范围、原子恢复和凭据存储需与实际实现持续核对。
- **验收**：错误地址/密码、离线、中断上传、合法备份和损坏恢复文件；预期不泄密、不半恢复。

## P024 登录档案

- **用户目标**：通过扫码、手机密码、短信验证码或 Cookie 等支持方式建立账号会话。
- **入口与出口**：任何需要账号的动作或个人页进入；成功返回发起位置并刷新账号能力，取消返回不丢原任务上下文。
- **信息层级**：登录方式 > 当前步骤输入/二维码 > 风控/错误 > 隐私说明与替代方式。
- **文字线框**：`关闭/标题 / 登录方式 / 表单或二维码 / 主操作 / 错误与帮助`。
- **设备适配**：Compact 单步纵向；Expanded 表单限宽居中，不做营销式左右分栏；键盘不遮验证码/提交。
- **组件清单**：`LoginScreen`、分段/方式菜单、`AppTextField`、密码/验证码、二维码、`AppPrimaryButton`、错误/进度。
- **状态矩阵**：首次加载=显示可选方式；刷新=二维码更新/验证码状态；正常=等待输入或扫码；部分数据=一种方式失败可切其他方式；空=不适用；失败=字段/网络/风控原因与下一步；离线=明确无法联网登录；未登录=本页核心；权限不足=相机若扫码需要时解释并可显示手动方式；禁用=字段无效/倒计时/提交中；分页加载/结束=不适用。
- **交互和返回**：提交防重复；验证码倒计时可信；成功一次写入会话并返回；取消不清空无关页面；二维码过期可刷新。
- **权限/登录**：凭据仅用于 Bilibili 接口；密码/Cookie/验证码不进日志、分享或普通崩溃信息。
- **性能**：二维码轮询有界、页面离开停止；输入不触发全屏高频重组。
- **无障碍**：字段标签、密码显示、倒计时、错误和替代登录方式可读；二维码提供状态文字。
- **当前差距**：多登录方式、风控补扫码与账号刷新链路复杂，需要端到端验证。
- **验收**：取消、错误凭据、验证码倒计时、二维码过期、成功返回来源；预期会话只建立一次且无凭据泄露。

## P030 首次引导档案

- **用户目标**：在首次启动理解必要选择并进入应用，而不是阅读功能广告。
- **入口与出口**：仅 onboardingRequired 时作为初始栈；完成进入主容器，返回/跳过按产品策略。
- **信息层级**：当前必要决定 > 简短理由 > 主要继续/跳过 > 步骤进度。
- **文字线框**：`进度/标题 / 当前选择内容 / 主要动作 / 次要跳过或返回`。
- **设备适配**：所有 viewport 首屏保留下一步可见；宽屏内容限宽，不使用巨型空白 Hero。
- **组件清单**：`OnboardingScreen`、分步状态、选择控件、`AppPrimaryButton`、权限解释（不直接抢先请求）。
- **状态矩阵**：首次加载=本地默认值；刷新=不适用；正常=步骤；部分数据=可选在线说明失败不阻塞；空=不适用；失败=保存失败可重试；离线=核心引导可完成；未登录=允许后续登录；权限不足=在真正用功能时请求或本步清楚说明；禁用=未完成必要选择；分页加载/结束=不适用。
- **交互和返回**：每步一个主要决定；完成只执行一次并替换到主容器；跳过后可在设置找到相关选项。
- **权限/登录**：不把可选权限或登录伪装为必须，说明拒绝后的功能差异。
- **性能**：无重图/持续特效阻塞启动；本地状态快速。
- **无障碍**：步骤、选项、进度和按钮完整可读；焦点随步骤移动。
- **当前差距**：引导内容与现有功能变化需定期核对，避免过时承诺。
- **验收**：全新状态完成、跳过、中途返回、旋转、离线；预期不重复引导且所有选择可在设置修改。

## P060 应用内网页档案

- **用户目标**：在应用内查看受支持网页，知道当前域名并可返回或交给外部浏览器。
- **入口与出口**：搜索/文章/系统通知/插件链接进入，携带 URL 与可选标题；出口到安全应用内路由、外部浏览器或返回。
- **信息层级**：返回/标题与来源 > 网页内容 > 加载进度/错误 > 外部打开等工具。
- **文字线框**：`返回+标题+更多 / 线性进度 / Web内容 / 错误覆盖（仅内容区）`。
- **设备适配**：Web 内容填充安全区；键盘、文件选择和宽屏不遮宿主导航。
- **组件清单**：`WebViewScreen`、`AppTopBar`、进度、错误/重试、外部打开菜单。
- **状态矩阵**：首次加载=显示域名/进度；刷新=重新加载当前 URL；正常=页面；部分数据=资源失败由 Web 与宿主合理提示；空=空 URL 按错误；失败=网络/协议/SSL 按安全策略；离线=明确；未登录=应用不得自动注入未授权凭据；权限不足=文件/相机/位置逐项按需；禁用=不支持/危险协议；分页加载/结束=不适用。
- **交互和返回**：返回优先 Web 历史还是离开由明确策略；外链协议白名单；下载/文件选择有来源提示。
- **权限/登录**：不默认共享应用 Cookie/token；Web 权限逐次解释；URL 脱敏日志。
- **性能**：WebView 生命周期与页面绑定；离开停止媒体/脚本按策略；不重复创建。
- **无障碍**：宿主返回和更多菜单可达；标题/域名可读；Web 内容遵循系统 WebView 能力。
- **当前差距**：Web 历史返回、Cookie 边界和外部协议需安全专项审计。
- **验收**：正常/重定向/离线/无效/外部协议、Web 内返回；预期来源可见且无法逃逸宿主安全边界。

## P061 未知旧路由兼容档案

- **用户目标**：当旧路由无法识别时安全回到可用页面，而不是崩溃或显示空白。
- **入口与出口**：旧深链/通知/兼容映射产生；当前内容角色回退 HOME，出口为首页正常导航。
- **信息层级**：可用首页内容 > 必要的一次性“不支持链接”说明；不得显示原始敏感 route。
- **文字线框**：`主外壳 / 首页 / 可选一次性非阻塞提示`。
- **设备适配**：跟随首页/主外壳，不创建未知空 Screen。
- **组件清单**：HOME 内容角色、可选 `AppSnackbar`、日志脱敏策略。
- **状态矩阵**：首次加载=直接安全回退；刷新/正常/部分数据/空/失败/离线/未登录/权限不足/禁用/分页加载/结束=均由首页档案处理；兼容层本身不得持有业务加载。
- **交互和返回**：未知路由不重复 push；回退后返回栈必须有效；同一坏链接不循环重新打开。
- **权限/登录**：不解析/展示未知参数中的敏感值，不申请任何权限。
- **性能**：常量时间回退，不做网络探测或反复解析。
- **无障碍**：若提示，简短说明“此链接暂不支持，已返回首页”，只播报一次。
- **当前差距**：当前 `Unknown` 映射为 HOME 内容角色，但是否提供用户提示需产品决策。
- **验收**：构造未知、缺参数、旧格式路由；预期不崩溃、不循环、不泄露原 route，并落到有效首页。

## 当前差距

外部内容、Web、插件与凭据交界处的风险高，当前规范只记录 UI 与交互合同，不宣称完成安全审计。`Unknown` 的用户提示尚未成为已实现事实。

## 验收方法

使用无真实敏感数据的测试账号/服务，覆盖取消、错误、离线、不受信来源和成功路径；检查日志与分享内容不含凭据，返回栈始终可用。
