## 初学者解释

社区页面强调内容关系和互动，消息页面强调时间、未读和通信结果。它们共同需要诚实的状态：未登录不是网络失败，发送中不是已发送，某张图片失败也不应让整条动态消失。

## 规范要求

- 时间顺序、未读和发送状态必须可信，不能靠颜色一种方式表达。
- 富文本、链接、图片和评论的局部失败要保留仍可读的内容。
- 长按复制、图片手势等能力必须有可发现的替代路径。

<a id="p004"></a>
## P004 动态档案

- **用户目标**：按关注关系浏览动态，刷新并进入作者、视频、番剧、直播或动态详情。
- **入口与出口**：主导航进入；出口到登录、首页、视频、番剧、动态详情、用户空间和直播。
- **信息层级**：发布者与时间 > 动态正文/媒体 > 转发对象 > 互动与统计。
- **文字线框**：`动态顶部栏 / 可选关注筛选 / 动态卡流 / 刷新与分页 / 图片或评论弹层`。
- **设备适配**：Compact 单列；Expanded 限制正文阅读宽度，可显示侧栏但不把卡片拉满；图片网格比例稳定。
- **组件清单**：`AppScaffold`、动态 TopBar、`ContentCardSurfacePolicy`、`UserLevelBadge`、富文本、图片网格、互动按钮、PullToRefresh、Sheet/Dialog。
- **状态矩阵**：首次加载=卡片占位；刷新=保留旧流；正常=动态流；部分数据=单媒体/转发/统计失败局部提示；空=未关注或暂无动态并给入口；失败=重试；离线=缓存+标明；未登录=登录引导而非错误；权限不足=受限媒体说明；禁用=删除/失效动态不可互动；分页加载/结束=尾部状态。
- **交互和返回**：整卡与内部链接按实际对象跳转；图片预览返回原卡；评论/转发弹层先关闭；详情返回恢复流位置。
- **权限/登录**：浏览公开内容可降级；关注流与互动需要登录时说明用途；保存图片权限按系统版本请求。
- **性能**：Lazy 列表稳定 dynamic ID；富文本解析缓存；GIF/图片按可见性加载；视频预览不抢正式播放器 session。
- **无障碍**：按发布者、正文、媒体描述、互动顺序读取；相同统计不重复；图片预览有关闭和页码语义。
- **当前差距**：动态领域仍有专用 ActionButton、复杂卡片与局部状态组件，需按语义逐项收口。
- **验收**：混合图文/视频/转发动态下刷新、预览图片、开详情并返回；预期无位置丢失、误触整卡或局部失败遮整卡。

<a id="p039"></a>
## P039 消息中心档案

- **用户目标**：查看消息分类、未读概况与最近会话，并进入具体消息或聊天。
- **入口与出口**：从首页/个人页进入；出口到回复、@、赞、系统通知、聊天及内容深链。
- **信息层级**：未读分类 > 会话列表 > 发送者/摘要 > 时间与状态。
- **文字线框**：`返回+消息 / 四类快捷入口 / 会话列表 / 加载或空状态`。
- **设备适配**：Compact 分类在上、会话在下；Expanded 可列表-会话双栏，首次无选择显示占位。
- **组件清单**：`AppTopBar`、分类列表项、badge、会话 `AppListItem`、头像、共享状态、`AppSplitLayout`（目标宽屏）。
- **状态矩阵**：首次加载=分类与会话占位；刷新=保留消息；正常=分类+会话；部分数据=某分类计数失败不遮会话；空=暂无消息；失败=重试；离线=缓存并标明；未登录=明确登录入口；权限不足=不适用；禁用=失效会话可见不可进入并说明；分页加载/结束=会话尾部。
- **交互和返回**：分类和会话跳转不破坏主导航；宽屏返回先关闭会话选择；读取后未读状态及时且可恢复更新。
- **权限/登录**：必须登录；未登录不发起无意义消息请求；隐私内容不出现在普通日志。
- **性能**：会话稳定 ID；未读更新局部；头像和摘要不反复解析。
- **无障碍**：读出发送者、摘要、时间、未读数量；已读/未读不只靠颜色。
- **当前差距**：宽屏列表-会话合同和未读状态的统一可访问表达仍需验证。
- **验收**：未登录、空会话、有未读、离线缓存四种状态进入；预期入口、计数、跳转和返回都诚实一致。

<a id="p040"></a>
## P040 回复我的档案

- **用户目标**：查看他人对自己内容的回复并跳转原内容或用户。
- **入口与出口**：消息中心进入；出口到相关视频/动态/文章、用户空间和返回。
- **信息层级**：回复者与动作 > 回复内容 > 原内容摘要 > 时间/已读。
- **文字线框**：`顶部栏 / 回复列表 / 分页状态`。
- **设备适配**：Compact 单列；Expanded 限制阅读宽度，可与消息分类并排。
- **组件清单**：`AppListItem`/消息卡、头像、富文本、原内容轻表面、状态组件。
- **状态矩阵**：首次加载=行占位；刷新=保留；正常=回复列表；部分数据=原内容失效仍显示回复；空=暂无回复；失败=重试；离线=缓存；未登录=登录；权限不足=删除/不可见内容说明；禁用=失效跳转禁用；分页加载/结束=尾部。
- **交互和返回**：点击回复进入准确上下文；内部用户名与原内容动作不冲突；返回恢复消息位置。
- **权限/登录**：必须登录；内容不可见时不泄露原文。
- **性能**：富文本缓存，分页去重，头像按尺寸加载。
- **无障碍**：读出“某人回复了你”、内容和时间；链接可单独操作且有名称。
- **当前差距**：富文本链接、原内容失效与长按复制的行为需要统一验证。
- **验收**：测试普通回复、楼中楼、原内容失效和分页失败；预期仍可理解回复来源且恢复动作明确。

<a id="p041"></a>
## P041 @ 我的档案

- **用户目标**：查看哪些内容提到了自己并进入上下文。
- **入口与出口**：消息中心进入；出口到原内容、用户空间和返回。
- **信息层级**：提及者 > 提及上下文 > 原内容 > 时间/已读。
- **文字线框**：`顶部栏 / 提及列表 / 分页`。
- **设备适配**：与 P040 相同的消息列表宽度规则。
- **组件清单**：消息卡、头像、富文本、状态组件。
- **状态矩阵**：首次加载=占位；刷新=保留；正常=@ 列表；部分数据=原内容缺失局部说明；空=暂无提及；失败=重试；离线=缓存；未登录=登录；权限不足=内容不可见说明；禁用=失效项不跳转；分页加载/结束=尾部。
- **交互和返回**：点击打开准确提及位置；用户名和原内容链接区分；返回保留位置。
- **权限/登录**：必须登录；不可见内容不泄露摘要。
- **性能**：分页去重，富文本解析缓存。
- **无障碍**：明确读出“提到了你”，而非只读用户名与碎片文字。
- **当前差距**：与回复列表的共享消息卡语义需要进一步收口。
- **验收**：打开包含文本、图片和失效原文的提及；预期内容顺序与深链准确。

<a id="p042"></a>
## P042 收到的赞档案

- **用户目标**：查看谁对自己的哪些内容点赞，并理解合并计数。
- **入口与出口**：消息中心进入；出口到用户和被赞内容。
- **信息层级**：点赞者/合并人数 > 被赞对象 > 时间与已读状态。
- **文字线框**：`顶部栏 / 点赞消息列表 / 分页`。
- **设备适配**：Compact 单列，Expanded 限宽；合并头像不挤压对象标题。
- **组件清单**：消息 `AppListItem`、头像组、对象摘要、badge、状态组件。
- **状态矩阵**：首次加载=行占位；刷新=保留；正常=赞列表；部分数据=部分用户/对象缺失时显示可用信息；空=暂无赞；失败=重试；离线=缓存；未登录=登录；权限不足=对象不可见说明；禁用=失效对象不可点；分页加载/结束=尾部。
- **交互和返回**：点击对象与用户入口分离；合并消息展开若支持必须有明确动作。
- **权限/登录**：必须登录，不展示受限内容明文。
- **性能**：头像组限制数量；列表 key 使用消息 ID。
- **无障碍**：合并读作“某某等 3 人赞了你的……”，不用逐个读装饰头像。
- **当前差距**：合并消息和多头像的读屏语义需核对。
- **验收**：单人、多人与对象失效三类消息；预期计数、对象和跳转准确。

<a id="p043"></a>
## P043 系统通知档案

- **用户目标**：阅读平台系统通知并安全打开支持的链接。
- **入口与出口**：消息中心进入；出口到应用内支持内容、Web 或返回。
- **信息层级**：通知标题 > 正文 > 时间 > 可选动作。
- **文字线框**：`顶部栏 / 通知列表 / 分页`。
- **设备适配**：限制正文阅读宽度；长通知换行，不用横向滚动。
- **组件清单**：通知卡/`AppListItem`、富文本链接、时间、状态组件。
- **状态矩阵**：首次加载=占位；刷新=保留；正常=通知；部分数据=不支持链接仍显示正文；空=暂无通知；失败=重试；离线=缓存；未登录=登录；权限不足=不适用；禁用=不支持动作禁用并保留文本；分页加载/结束=尾部。
- **交互和返回**：仅可信协议使用应用内路由，其他链接明确进入 Web；返回保留阅读位置。
- **权限/登录**：必须登录；通知内容和链接不得泄露凭据。
- **性能**：富文本与链接解析缓存，列表 key 稳定。
- **无障碍**：标题、正文、时间顺序完整；链接提供目的名称。
- **当前差距**：系统通知链接路由与不支持协议的文案需要持续审计。
- **验收**：普通文本、应用内链接、Web 链接和无效链接逐项操作；预期无崩溃、误路由或信息丢失。

<a id="p044"></a>
## P044 私信会话档案

- **用户目标**：阅读与指定用户的历史消息并发送新消息。
- **入口与出口**：会话列表或用户入口进入；可打开内容链接、用户空间并返回消息中心。
- **信息层级**：会话对象 > 时间顺序消息 > 发送输入 > 消息发送状态。
- **文字线框**：`返回+用户名 / 消息时间流 / 新消息提示 / 输入框+发送`。
- **设备适配**：Compact 全页会话；Expanded 可作为消息中心详情栏；键盘出现不遮最新消息和输入。
- **组件清单**：`AppTopBar`、消息气泡、时间分隔、`AppTextField`、发送 `AppIconButton`、加载/重试、链接菜单。
- **状态矩阵**：首次加载=历史占位且输入状态明确；刷新=向上加载保留锚点；正常=可收发；部分数据=单消息媒体失败可重试；空=新会话提示；失败=历史失败/发送失败分别处理；离线=可输入但发送明确排队或失败，不能伪装成功；未登录=返回登录；权限不足=受限会话说明；禁用=发送条件不满足时说明；分页加载=顶部历史进度；分页结束=最早消息提示。
- **交互和返回**：发送按钮防重复；发送中/成功/失败状态可信；返回关闭键盘后离开规则明确；滚动离开底部时新消息不强制跳转。
- **权限/登录**：必须登录；输入和消息不进入普通日志；媒体权限按选择附件时请求。
- **性能**：反向/锚点列表稳定 ID；新消息局部插入；长会话有界加载。
- **无障碍**：读出发送者、内容、时间和发送状态；输入标签与发送动作清楚；气泡颜色不是唯一方向标识。
- **当前差距**：离线发送、失败重试和宽屏列表-会话的统一行为需设备验证。
- **验收**：空会话发送、断网发送、失败重试、收到新消息和加载旧消息；预期顺序、状态与滚动锚点可信。

<a id="p054"></a>
## P054 专栏文章详情档案

- **用户目标**：完整阅读文章并打开其中支持的内容链接。
- **入口与出口**：历史、搜索或内容链接进入；出口到 Web/应用内内容、作者空间和返回来源。
- **信息层级**：标题 > 作者/时间 > 正文媒体 > 相关操作与内容。
- **文字线框**：`返回+标题 / 文章标题与元信息 / 正文 / 媒体与链接 / 底部操作`。
- **设备适配**：Compact 单栏；Expanded 严格限制正文行宽，图片按内容宽度不拉伸。
- **组件清单**：`AppScaffold`、文章 TopBar、`AppText`/富文本、图片、链接、加载/错误。
- **状态矩阵**：首次加载=标题可用则先显示+正文占位；刷新=保留正文；正常=完整文章；部分数据=图片/链接失败不清空文字；空=正文确实为空时说明；失败=重试/返回；离线=缓存正文；未登录=公开阅读；权限不足=受限文章说明；禁用=失效链接不可点；分页加载/结束=长文通常不适用。
- **交互和返回**：链接按可信路由打开；图片查看可关闭回正文位置；返回来源列表。
- **权限/登录**：公开内容不强制登录，受限内容明确原因。
- **性能**：富文本解析不阻塞组合；长文分块/懒加载；图片按宽度解码。
- **无障碍**：正确标题层级、段落顺序、图片说明与链接名称；不把全文合并成一个节点。
- **当前差距**：文章布局已抽取 Screen，但复杂富文本与动态文章路由回退仍需验证。
- **验收**：长文、图片失败、应用内/外链和离线缓存；预期正文可持续阅读且返回位置合理。

<a id="p055"></a>
## P055 动态详情档案

- **用户目标**：查看单条动态完整内容、评论上下文和相关媒体。
- **入口与出口**：动态流、搜索或深链进入；出口到视频、番剧、直播、用户、评论楼中楼和返回来源。
- **信息层级**：发布者/时间 > 完整正文/媒体 > 互动 > 评论与回复上下文。
- **文字线框**：`返回 / 动态内容 / 互动操作 / 评论排序与列表 / 回复弹层`。
- **设备适配**：Compact 单栏；Expanded 内容与评论可合理分区但保持正文优先。
- **组件清单**：动态卡内容、富文本、媒体预览、互动按钮、评论列表、Sheet/Dialog、状态组件。
- **状态矩阵**：首次加载=主体与评论分区占位；刷新=保留主体；正常=主体+评论；部分数据=评论或媒体局部失败；空=无评论不是无动态；失败=主体失败整页重试；离线=缓存主体、互动禁用说明；未登录=浏览公开内容，互动引导登录；权限不足=受限内容说明；禁用=已删除/互动关闭；分页加载/结束=评论尾部。
- **交互和返回**：深链到评论时准确定位；预览/楼中楼先关闭；返回恢复来源动态；互动防重复。
- **权限/登录**：发布/互动需登录，保存媒体按需申请权限。
- **性能**：正文与评论分开加载；富文本缓存；预览媒体生命周期有界。
- **无障碍**：主体、互动、评论顺序；回复关系可理解；互动状态不只颜色。
- **当前差距**：评论 Sheet、楼中楼和深链目标初始化复杂，局部状态合同需更多测试。
- **验收**：普通进入、评论深链、评论失败、图片预览与返回；预期主体不因评论失败消失，焦点/位置正确。

## 当前差距

社区富文本、评论弹层与消息卡存在不同领域复杂度。共享的是状态、卡面、身份和无障碍合同，不要求把所有业务组件放进同一个文件。

## 验收方法

以未登录、已登录、离线、局部媒体失败、分页失败五类状态贯穿动态和消息；检查内容不被误清空、未读/发送状态可信、返回与深链准确。
