## 初学者解释

验收不是“我看着挺好”，而是给定环境、步骤和预期结果后，另一个人也能得出相同结论。本手册分为机器能检查的结构合同与必须在设备上操作的行为合同。项目规则禁止以截图作为本套规范的输入或验收要求，因此人工结果用文字记录。

### Miuix 完整矩阵

Miuix 是主设计基准，以下组合必须覆盖。AMOLED 本质为主题模式，至少在 Compact 与 Expanded 各完整执行一次，其余宽度核对背景和弹层即可。

| 可用宽度 | 浅色 | 深色 | AMOLED | 重点 |
|---:|:---:|:---:|:---:|---|
| 360dp Compact | 完整 | 完整 | 完整 | 最长文本、底栏、触摸区、键盘 |
| 约 700dp Medium | 完整 | 完整 | 核心 | 导航切换、列数与最大宽度 |
| 840dp Expanded | 完整 | 完整 | 完整 | 设置双栏、侧栏、返回 |
| 1000dp Expanded | 完整 | 完整 | 核心 | 列表-详情、内容不拉伸 |
| 1600dp Media | 媒体完整 | 媒体完整 | 媒体核心 | 视频/番剧/直播多区域布局 |

“完整”指至少覆盖：首页、搜索、视频详情与播放器、动态、个人空间、消息、内容库、直播/番剧/音频、设置、登录/权限，以及通用弹层的 12 种状态中可触发项。

### iOS 与 Material 3 兼容矩阵

两种兼容风格分别检查：

1. 手机浅色与深色：首页 → 搜索 → 视频详情/播放器 → 返回。
2. 手机浅色与深色：个人页 → 设置 → 修改一个可恢复选项 → 返回。
3. 通用弹层：确认、错误、底部面板、Snackbar、Tooltip。
4. 一个 840dp 以上平板流程：主导航 → 设置双栏 → 视频宽屏。
5. 所有流程的功能、信息顺序、状态、可访问名称和 48dp 触摸区与 Miuix 相同。

### 状态矩阵执行法

每个页面从[页面母版](08_PAGE_TEMPLATES.md)的 12 项状态选择适用项。不能稳定制造的服务端错误可以通过测试状态、断网或受控假数据验证；不得修改真实用户数据来“试一试”。删除、清空、恢复等操作只能使用可恢复测试数据。

### 关键流程预期

| 流程 | 必须验证的结果 |
|---|---|
| 首页到详情再返回 | 来源列表状态合理保留；无黑底、双卡或错误播放器所有权 |
| 搜索到结果 | 查询、筛选和返回后的输入保持符合档案 |
| 播放与全屏 | 缓冲/播放/暂停清楚；手势不冲突；退出恢复详情 |
| PiP/后台 | 系统媒体状态与应用一致，返回不会反向触发 |
| 设置 | 修改立即或按文案规定生效，重进后持久化 |
| 登录/权限 | 原因与后果明确，拒绝或取消后可恢复 |
| 删除/清理 | 对象与范围明确，UI 与数据结果一致 |

## 验收方法

先运行结构测试，再由用户按本页矩阵执行人工步骤。每个失败记录页面 Key、环境、前置状态、最短复现、实际和预期结果；不要求、读取或分析截图。
